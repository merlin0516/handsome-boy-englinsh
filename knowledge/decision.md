# 待決策事項

只記錄需要方向選擇、但目前可先採暫定方案推進的事項。決策有新證據時可更新。

## D-001：第一版交付形式

- **狀態：** 暫定採用，等待使用回饋
- **問題：** 第一版應先做成網站、手機 App，或學習計畫？
- **推薦：** 先做可直接在瀏覽器開啟的靜態網頁原型，讓程度選擇、練習與升等循環先可操作；有實際需求後再決定部署或 App。
- **理由：** 目前沒有指定平台、帳號或同步需求；靜態原型成本低，也能快速收集對題目與升等節奏的回饋。
- **影響範圍：** 第一版的使用方式與資料保存。現在使用 `localStorage`，僅保存於目前瀏覽器。

## D-002：程度與學測級分的對應

- **狀態：** 暫不建立正式對照
- **問題：** 初／中／進階是否要對應學測級分？
- **推薦：** 現階段將程度當作練習難度選擇，不宣稱可以預測正式級分；等累積正式題型、能力指標和學習成效資料後再評估對照方式。
- **理由：** 目前只有少量自編示例題，沒有足以支持級分推估的題庫或驗證資料。
- **影響範圍：** 程度名稱、學習成效文案和後續測驗設計。

## D-003：程度選擇方式

- **狀態：** 暫定使用者自行選擇，可隨時切換
- **問題：** 是否需要入門測驗來推薦程度？
- **推薦：** 先讓使用者自行選擇初／中／進階並可切換，待題庫與能力指標成熟後再加入選級測驗。
- **理由：** 目前題目數不足以做可靠分級；自選可立即體驗並降低開始門檻。
- **影響範圍：** 第一版上手流程與題目資料量需求。

## D-004：GitHub 推送認證

- **狀態：** 2026-11-26 已確認推送成功
- **問題：** 先前一次非互動推送因找不到憑證失敗；目前工作副本已追蹤遠端 `master`，表示遠端分支存在，但不代表目前環境一定有寫入權限。
- **推薦：** 每次完成階段後直接嘗試一般 `git push`；若認證失敗，保留本機提交，請倉庫擁有者在 Git Credential Manager 登入後重試。不要把密碼或 token 貼在聊天或提交到專案。
- **理由：** 讀取公開倉庫與推送寫入使用的權限不同；以實際推送結果判定狀態。
- **影響範圍：** `origin` 指向 `https://github.com/merlin0516/handsome-boy-englinsh.git`；使用 `git -c credential.interactive=never push origin master` 成功推送，遠端已包含本機最新提交。之後可先以非互動模式重試，避免等待登入視窗。

## D-005：外部題目覆核與寫作回饋

- **狀態：** 審查包與本機寫作回饋已備妥；外部覆核待有審查者時進行
- **問題：** 題目程度、答案和解說需要第二位教師或同儕覆核，但目前沒有指定審查者，也沒有可代為聯絡的對象。
- **推薦：** 提供每程度分開保存的「優點／待釐清問題／下一稿修改」紀錄欄，並準備答案遮蔽的題目表、分離的答案解說表及審查指南。取得審查者後，請先獨立作答，再核對答案、解說和程度標籤。
- **理由：** 本機提示改善回饋可操作性，不需帳號或上傳草稿；獨立審查表以題庫單一來源匯出，答案分開可減少預設答案影響判斷。外部覆核仍必須由真人完成，不能把自我檢查寫成獨立審查。
- **影響範圍：** 寫作練習互動、題庫品質保證與正式發布準備。回饋只存於目前瀏覽器，不跨裝置同步；審查檔可交由教師離線填寫。

## D-006：本機練習統計方式

- **狀態：** 暫定採用，等待使用者回饋
- **問題：** 如何在無帳號與後端的原型中呈現每日活動、整體正確率及題型表現？
- **推薦：** 彙總目前裝置近 90 個本地日曆日的作答次數，顯示今天與近 7 天的練習量，並按主要題型計算作答次數中的答對比例；合併所有程度，舊版歷史不回填。
- **理由：** 記錄聚合後不保存逐題時間線，也避免用少量自編題推估能力或正式級分；本地日曆日期與每週任務一致。
- **影響範圍：** `localStorage` 增加日期、程度、題型、作答數和答對數的聚合欄位；資料只在此裝置保存，清除進度會一併重設。

## D-007：錯題間隔複習試行規則

- **狀態：** 暫定採用，已手動驗收但尚未校準
- **問題：** 在沒有學習成效資料時，如何決定錯題再次出現的時點？
- **推薦：** 答錯後隔 1 個本地日曆日複習；複習答對後依序隔 3、7、14 天再出現，完成 14 天階段後移出排程；任一階段答錯都重設為隔天。使用者仍可主動複習所有錯題。
- **理由：** 固定、可理解的短排程能先形成可用的回顧循環；明示試行與未校準，避免把它描述成已驗證的最佳間隔。
- **影響範圍：** 錯題排程只存在本機，依裝置日曆日期計算；日後需以實際使用與延遲記憶表現資料調整間隔。
