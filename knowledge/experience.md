# 經驗紀錄

記錄實作中可重複使用的做法與限制。每筆經驗需註明未來適用範圍，避免把單一決策誤當通用規則。

## 2026-11-19：無後端學習原型

- **情境：** 專案剛開始，尚未決定部署、帳號或後端架構，但需要讓「選擇英文程度並升等」變成可操作的成果。
- **做法：** 以單一靜態 HTML 頁面、CSS、原生 JavaScript 和 `localStorage` 做出本機原型；先提供初／中／進三種練習、即時解說、答對 XP、等級進度及裝置內保存。
- **觀察：** 靜態頁面能低成本驗證程度選擇和升等循環。題目答對後以「程度＋題目索引」記錄，避免同一題在同一程度反覆刷 XP；更換程度仍可繼續練該程度的題目。
- **限制：** 進度只留在目前瀏覽器，不會跨裝置同步；題庫量少且示例題未經教學專家審校；XP、等級與題目難度目前是產品原型規則，不代表學測級分。
- **未來可用範圍：** 適用於早期概念驗證、靜態學習工具、離線原型或尚未確定後端的個人專案。若要多人使用、跨裝置保存、正式評量或大規模題庫，需改用持久化後端、題目資料格式與內容審核流程。

## 待累積

- 使用者實際練習與程度切換回饋。
- 題目品質檢查與難度標記方式。
- XP／複習節奏是否能鼓勵持續學習的證據。
