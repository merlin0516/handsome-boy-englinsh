# 經驗紀錄

記錄實作中可重複使用的做法與限制。每筆經驗需註明未來適用範圍，避免把單一決策誤當通用規則。

## 2026-11-19：無後端學習原型

- **情境：** 專案剛開始，尚未決定部署、帳號或後端架構，但需要讓「選擇英文程度並升等」變成可操作的成果。
- **做法：** 以單一靜態 HTML 頁面、CSS、原生 JavaScript 和 `localStorage` 做出本機原型；先提供初／中／進三種練習、即時解說、答對 XP、等級進度及裝置內保存。
- **觀察：** 靜態頁面能低成本驗證程度選擇和升等循環。題目答對後以「程度＋題目索引」記錄，避免同一題在同一程度反覆刷 XP；更換程度仍可繼續練該程度的題目。
- **限制：** 進度只留在目前瀏覽器，不會跨裝置同步；題庫量少且示例題未經教學專家審校；XP、等級與題目難度目前是產品原型規則，不代表學測級分。
- **未來可用範圍：** 適用於早期概念驗證、靜態學習工具、離線原型或尚未確定後端的個人專案。若要多人使用、跨裝置保存、正式評量或大規模題庫，需改用持久化後端、題目資料格式與內容審核流程。

## 2026-11-19：分級題庫與能力指標

- **情境：** 初版每級題目太少，尚未涵蓋全部主要練習類型，程度命名也缺少可供編題參考的描述。
- **做法：** 擴充各級混合題型，並以獨立課綱文件記錄暫行能力描述、建議技能順序和題目校準原則。
- **觀察：** 先用可觀察的任務描述程度（如找明示細節、理解段落、評估論述證據），比直接宣稱等同學測級分更能在缺少驗證資料時維持誠實，也方便後續按回饋調整。
- **限制：** 目前每級僅有少量自編題，不能代表完整題型覆蓋或可靠分級；寫作尚未具備自動回饋。
- **未來可用範圍：** 適用於教育原型的初版課綱、題庫標記與內容審查規則。若用於正式課程或測驗，需由教師審核、擴增題庫並以實際作答資料校準難度。

## 2026-11-19：錯題複習與本機紀錄

- **情境：** 單純 XP 累積不能引導學習者回頭處理答錯內容。
- **做法：** 在本機進度中分開保存每題作答次數、已獲得 XP 的題目和錯題清單；提供依目前程度篩選的錯題複習，答對後從錯題清單移除。舊版儲存資料缺少新欄位時，初始化空物件以維持相容。
- **觀察：** 把「練過幾次」、「曾答對並領取 XP」與「目前待複習」分開記錄，能避免重答刷 XP，也能把錯題回饋轉成後續練習入口。
- **限制：** 記錄仍只在單一瀏覽器；目前錯題複習只涵蓋所選程度，沒有間隔重複排程，也未測量延遲後是否記住。
- **未來可用範圍：** 適用於小型本機學習工具的錯題工作流和簡單進度模型。需要跨裝置、長期學習分析或可靠同步時，應遷移到有版本與帳號管理的持久化儲存。

## 2026-11-19：分級寫作提示與草稿保存

- **情境：** 學測英文練習計畫包含寫作，但初版只有選擇題，且自動評分會超出目前題庫與驗證能力。
- **做法：** 按程度提供由短描述到論述表達的提示，加入英文單字數、自我檢查清單，並將不同程度的草稿和檢查狀態分開存在本機。
- **觀察：** 不依賴自動評分也能讓寫作練習可開始、可保存；明示自我檢查是學習提示，避免把它誤解為能力評分。
- **限制：** 未自動評估文法、內容或組織品質；字數只計英文詞彙；草稿僅在目前瀏覽器保存。
- **未來可用範圍：** 適用於早期寫作練習工具或需要延續草稿的單機應用。若要提供品質評分或個人化回饋，需先定義評分準則、教師審查流程與隱私適當的內容處理方式。

## 2026-11-19：先文件化學習節奏

- **情境：** 原型已有不同練習功能，但尚未說明如何把它們安排成持續學習的路徑。
- **做法：** 先建立五次練習的週順序和四週循環，並對各程度提供可調整的任務尺度；明確標示時長與節奏只是建議，網站尚未追蹤排程。
- **觀察：** 在加入提醒、連續天數或強制目標前，先提供低壓、可調整的學習安排，能讓使用者開始實作，也避免把未驗證的節奏包裝成保證有效的方法。
- **限制：** 尚無使用者資料驗證頻率、時長或順序；安排尚未整合進網站。
- **未來可用範圍：** 適用於學習產品早期的課程草案與內容排序。正式產品化前，應用學習者回饋調整負擔，並讓任務追蹤和提醒由使用者選擇啟用。

## 2026-11-19：題目自我檢視與審查界線

- **情境：** 原型題目增加後，需要一套可重複的答案與文字品質檢查方式。
- **做法：** 建立逐題檢查清單，人工對照正解、解說、語境、程度和閱讀證據；把批次範圍、修訂和未完成的獨立覆核記錄下來。
- **觀察：** 檢查資料是否支持題目措辭，能避免將觀察結果誇大成因果結論；區分自我檢視與第二人覆核，也能讓信心界線更清楚。
- **限制：** 自我檢視不是獨立品質審查，程度標記尚未校準；瀏覽器互動與無障礙檢查尚未完整執行。
- **未來可用範圍：** 適用於小型題庫的編輯審查與發布前清單。重要或高影響評量需加入獨立學科審查、試答資料和版本追蹤。

## 待累積

- 使用者實際練習與程度切換回饋。
- 題目品質檢查與難度標記方式。
- XP／複習節奏是否能鼓勵持續學習的證據。
