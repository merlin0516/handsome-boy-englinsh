# 學測英文升等學習專案計畫

## 願景

打造一個以台灣大學學科能力測驗（學測）英文科為核心的學習專案，讓學習者能先選擇自己的英文程度，再透過循序漸進的練習提升能力與信心。學習內容聚焦字彙、文法、克漏字、閱讀理解與寫作；完成任務可累積經驗值、解鎖挑戰並逐步升等。

## 目前狀態

已完成可在瀏覽器開啟的靜態原型。使用者可自選初階、中階或進階，練習每級的自編題目、閱讀解說、累積 XP、複習錯題、保存寫作草稿及追蹤每週清單；進度保存在目前瀏覽器。2026-11-26 已完成主要互動與 390px 窄螢幕的瀏覽器手動檢查；題庫與學習規則仍屬原型，尚未經獨立審校或學習成效驗證。此工作副本追蹤 `origin/master`，推送認證需以新的推送結果確認。

第一版形式、級分對應、程度選擇和 Git 遠端目的地的建議記錄於 [decision.md](decision.md)。實作模式的可復用經驗記錄於 [experience.md](experience.md)。
