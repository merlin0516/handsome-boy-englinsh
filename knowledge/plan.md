# 學測英文升等學習專案計畫

## 願景

打造一個以台灣大學學科能力測驗（學測）英文科為核心的學習專案，讓學習者能先選擇自己的英文程度，再透過循序漸進的練習提升能力與信心。學習內容聚焦字彙、文法、克漏字、閱讀理解與寫作；完成任務可累積經驗值、解鎖挑戰並逐步升等。

## 目前狀態

已完成可在瀏覽器開啟的靜態原型。使用者可自選初階、中階或進階，練習每級 20 題自編題目、查看解說、累積 XP、複習錯題、保存寫作草稿與同儕回饋紀錄及追蹤每週清單；進度保存在目前瀏覽器。2026-11-26 已完成主要互動與 390px 窄螢幕的瀏覽器手動檢查，並成功推送至 `origin/master`。近期練習摘要依本地日期記錄近 90 天聚合資料；錯題試行排程為 1、3、7、14 天，尚未經學習成效校準。60 題獨立審查包已備妥，但尚無外部審查結果。

第一版形式、級分對應、程度選擇和 Git 遠端目的地的建議記錄於 [decision.md](decision.md)。實作模式的可復用經驗記錄於 [experience.md](experience.md)。

## 下一階段

下一步是依發布前清單補做鍵盤與無障礙檢查，並整理較長閱讀材料的設計規格；錯題間隔和練習摘要的統計仍需實際使用資料校準。審查包可供未來教師使用，但目前沒有可指定審查者或學習者；因此外部覆核和回饋仍待參與者。既有瀏覽器檢查限於目前瀏覽器與 390px 視窗，其他瀏覽器或真實手機仍待驗收。級分對照和跨裝置同步暫不阻塞其他工作。
